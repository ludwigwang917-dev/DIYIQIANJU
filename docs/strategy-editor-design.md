# 策略编辑器设计（2026-11-24）

> 状态：第 1 步已完成（2026-11-24，见 `PROJECT_CONTEXT.md` F-20），第 2–5 步未开始。决策记录见 P-3 / P-4。

## 一、目标

让每个人定制自己的托管策略：策略可以读取**桌上任何人能看到的信息**，按自己写的规则调整下注。
教育点：真实赌客信的“规律”（庄家连赢该输了、跟手气好的人、看路单、换荷官后加注……）几乎都建立在公开信息上。
每局 54 张重新洗牌，公开信息不能预测下一手；跑够局数，每投注 1 点的输赢会回到理论值（−1.77% 到 −2.31%）。

Phase 2 的“一句话托管”与本编辑器共用同一份规则格式：模型只负责生成规则，结果显示在编辑器里供用户检查、修改。

## 二、已定决策（2026-11-24 负责人确认）

| 事项 | 决定 |
|---|---|
| 能读什么 | 桌上任何人能看到的信息，全部开放（见第三节）。 |
| 本局别人的注 | **能看到**本局已经下好的注（筹码在桌面上是明摆着的）。 |
| 规则怎么写 | **积木 + 公式**，存成 JSON 语法树；不允许写 JavaScript。 |
| 保存 | 浏览器本地（localStorage）+ 分享链接（配置编码在 URL `#` 之后，不发到服务器）；不做账号、不加数据库。 |

方案默认（负责人可改）：编辑器定制的是“我这个赌客”，即 下注规则 + 离场计划（现有 `VisitPlan`）+ 补仓习惯（把全局 `AUTO_REBUY` 变成个人参数）。

## 三、信息边界

**看不到**（结构上保证，不靠自觉）：本局还扣着的牌（含自己的）、随机种子、牌序。

**能看到**（斗牛的信息目录，变量名供积木选择器使用）：

| 类别 | 变量 |
|---|---|
| 我 | 本金、本次盈亏、买入次数、累计投入、本次已玩局数、连胜、连败、上局下注（前注/后注）、上局牌型、上局倍数、离场计划剩余（距止盈/止损/局数上限） |
| 庄家与荷官 | 当前荷官、本班已发局数、距换人局数、庄家最近 N 局牌型、庄家对全桌连赢/连输、路单（与多桌大厅的 `roadLog` 是同一份数据） |
| 其他座位 | 是否有人、本金、连胜/连败、上局下注与牌型、补仓次数；离场记录（谁、为什么） |
| 全桌 | 局数、洗牌次数、庄家累计盈亏、最近 N 局所有亮出的牌（各牌型出现次数、大小王出现次数等） |
| 本局 | 我是第几个下注；已经下好的座位各下了多少 |

## 四、架构

1. **公开记录（赌桌层）**：每局 showdown 后把可公开的内容追加进滚动窗口（建议最近 200 局）。与另一会话在做的 `roadLog` 合并为一份，不另起平行结构。
2. **`GameModule` 新增**：
   - `publicRecord(state, settlements)`：这局亮牌后哪些东西可以公开；
   - `observationCatalog()`：本游戏有哪些变量、中文名、类型、取值范围，编辑器直接读它；换游戏不用改编辑器。
3. **`observe(table, seatIndex)`（赌桌层）**：从公开记录 + `viewOf`（下注阶段牌全扣着）+ 本局已下注额 生成观察，这是策略**唯一**的输入。`StrategyInput` 由它取代；10 种预设改为从观察里取所需字段。
4. **常用指标逐局累加**（连赢、出现次数等），不在每次决策时重扫历史，保证蒙特卡洛百万局的性能。
5. **下注顺序**：既然能看到别人本局的注，顺序就必须明确。已实现为按座位号依次下注（`nextToAct`），手动座位也要轮到才能下。规则说明里还没写这一条，做编辑器界面时补上。
6. **策略引用**：`SeatControl` 的 `auto` 改为携带 `{ type: "preset", id } | { type: "config", config }`，`auto-play` 与蒙特卡洛请求直接传数据（Worker 看不到主线程注册表）。同种子重放自然成立。

### 关键契约测试

- **换牌序观察不变**：公开记录相同、只换本局牌序，`observe()` 输出必须完全相同。证明任何策略碰不到底牌。
- **预设等价**：10 种预设写成规则后，逐局比对与手写版下注完全一致。证明表达力够用。
- 规则策略也要通过现有的合规、零和、同种子一致、人机等价测试。

## 五、规则格式（积木 + 公式）

- 规则列表从上往下，第一条条件满足就用它；最后一条是“否则”。
- 每条：`条件 → 前注 = 表达式，后注 = 表达式`。
- 表达式：数字、变量、四则运算、比较、且/或/非、`如果(条件, a, b)`、`最小/最大/取整到10`，以及统计函数 `最近(N, 指标)`、`计数(N, 条件)`、`平均(N, 指标)`。
- **自定义计数器**（可选）：“每局结束后：如果 … 则 计数器 + 1 / 归零”。本质是对历史的逐局累加，可重放。
- **随机()**：每个座位一个从种子派生的独立随机数，不影响发牌随机数序列。
- 解释器自写，不用 `eval`；有运算步数上限；输出仍走 `clampToSpec` 和 `GameModule.validate`。界面上非法值直接标红，不悄悄修正。
- 格式带 `version` 字段；分享链接导入的配置是不可信数据，必须先过校验。

## 六、编辑器界面

- 入口：铭牌弹出的座位设置里策略下拉加“自定义…”；蒙特卡洛策略下拉加“我的策略”。
- 积木视图与公式文本视图可切换，对应同一棵语法树。
- 变量选择器按第三节分组，数据来自 `observationCatalog()`。
- 即时反馈：前 20 局下注预览（每局下多少、最坏输多少，用 `maxLoss`）；改完自动跑小样本蒙特卡洛，与平注同图对比，并显示“每投注 1 点的输赢”与理论值。
- 模板：“迷信策略”示例（庄家连赢反打、追热手、看路单、换荷官加注），可直接载入再改。

## 七、步骤

4. 即时蒙特卡洛对比、迷信模板、分享链接。
