## 视觉决定（已定）

| 项 | 决定 |
|---|---|
| 总方向 | 写实绿色绒布赌桌，重点是材质质感；不走实验室/霓虹风格 |
| 桌型 | 桌面：半月形（荷官一侧平边），5 座沿弧线；手机竖屏：竖向排列，庄家在上、玩家网格在下，材质不变 |
| 桌布 | 经典赌场绿 `#13603f`。绒面颗粒 + 绒毛高光 + 斜向绒面反光 + 染色不均 + 发牌区/下注框磨浅 + 顶灯光斑 + 边缘压暗 |
| 桌边 | 棕色软包皮革 + 缝线 + 铜色内包边 |
| 桌面印刷 | 赔率弧形字（含“同牌型庄家胜”）、前注/后注下注框、桌心“概率余烬”与“虚拟点数 · 不可兑换 · 纯概率模拟” |
| 道具 | 筹码托盘、发牌靴、弃牌堆；牌背为暗红菱格 + “余”字徽记 |
| 筹码 | 有厚度、侧边条纹和面值；10 象牙 / 50 酒红 / 100 墨黑 / 500 藏青 |
| 牌面 | 大号角标：左上大号衬线数字 + 小花色；右下数字牌为大花色，A 加细圈，J/Q/K 为小人头框；全部矢量绘制，不用系统字体花色符号 |
| 斗牛点数展示 | 手牌分“3 张凑整 + 2 张算点”留缝，凑牛的 3 张描金边；庄家结果牌写出算式（如 K+7+3=20 · 2+5=7 → 庄 · 牛七 ×2） |
| 座位铭牌 | 只放六样：头像、姓名、策略标签、总输赢（红/绿）、本局牛几、本局倍数（×N，赢绿输红；离场写“离席”）。牛几与倍数分开放（输时倍数取庄家牌型，不能写成“牛五 ×2”）。赢的座位淡绿光，手动座位金色描边 |
| 离场表现 | 下注框留灰烬和上飘火星，铭牌褪色，头像旁一颗余烬 |
| 页面材质 | 深色漆面板 + 铜色细边；标题衬线体（Noto Serif SC），数字 Georgia；主按钮铜金色，每处只有一个 |

## 桌面整页结构（已定）

1. 顶栏：铜章“余” + 品牌名 / 居中“无真实货币 · 纯模拟 · 教育目的” / 规则说明 · 分析证据 · 寻求帮助
2. 标题区：左标题与副文案；右侧仪表条（营业时钟、已开局数、在座、庄家累计、全桌统计）
3. 主区左：运行状态 + 速度切换 → 牌桌 → 操作台（暂停/继续、单步、重置）+ 右侧随状态切换：自动运行时为“上一局”播报，轮到手动座位时为下注面板（点筹码加到前注/后注，显示上限与本局最大可能损失）
4. 主区右：证据面板（净收益率、资金曲线、已离场/庄家累计、零和校验、多久输光）
5. 座位设置：点铭牌弹出小面板（托管/手动、策略列表、换人、请离席），替代原来塞在座位里的下拉框
6. 蒙特卡洛：策略选择 + 运行；结果为输光概率、破产局数直方图（最后一根斜纹 = 撑满 1,000 局）、三项事实
7. 三条结论 → 页脚求助资源与免责声明
8. 状态文字必须和实际运行状态一致（运行中/已暂停等你下注/已暂停设置座位）

## 手机竖屏（已定）

- 同一网址的响应式排法，不是单独的 App
- 顶部仪表三格（已开局、在座、庄家累计）+ 统计入口；营业时钟和副文案手机上不显示
- 牌桌竖向：庄家在上（3+2 分组），玩家 2×2 网格 + 最下一整行
- 暂停/继续、单步、重置、速度固定在屏幕底部
- 下注、座位设置都从底部弹出；筹码按钮 62px
- 往下依次：上一局播报 → 证据面板 → 蒙特卡洛（策略标签横向滑动）→ 三条结论 → 求助页脚

## 落地时和代码的对齐（2026-11-24 落地时的处理）

1. **没有专属“你”座位** —— 已处理：金色描边跟随任一手动座位；下注面板标题写座号 + 姓名，多个手动座位排队时注明“之后还有 N 个”。手机版最下一整行固定给 05 号座（五座同级，只是奇数排版）。
2. **补仓** —— 已处理：手动座位输光或注额超过余额时，操作台右侧（手机为底部弹层）换成补仓面板，写“第 N 次买入”“已买入 N 次 · 累计投入”，并提示补完后的累计投入；离席也在这里。铭牌仍只放六项，总输赢 = 余额 − 累计投入（补仓功能已这样定义）。
3. **离场原因** —— 铭牌不区分；“多久输光”列表写明归零 / 资金不足 / 主动离席。
4. **示意数据** —— 已全部接真实数据。
5. **最大可能损失** —— 取游戏模块 `maxLoss`；下注上下限取 `actionSpecFor`；补仓上限取 `maxRebuyAmount`。
6. **头像** —— 仍是单字圆章占位，画风未定。
7. **动效** —— 未设计（目前只有离场余烬的上飘火星）。
8. **设计稿外补充**：大小王牌面（左上“王”+大/小，右下星形人头框，大王红、小王黑）。
